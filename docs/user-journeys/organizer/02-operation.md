# 3. 活动运营与数据监控

- **角色：** 活动主创者 (Owner), 协同管理者 (Manager)
- **前置条件：** 活动已发布 (`status: published`)

在活动发布后，组织者团队的工作重心从“创建”转向“运营”。平台为此提供了一个专属的活动仪表盘，作为运营和监控的枢
心。

## 3.1 活动仪表盘入口

| 角色 | 入口位置 | 说明 |
|------|----------|------|
| **主创者/协同管理者** | 在其拥有管理权限的活动页面，顶部或侧边栏会出现一个仅管理者可见的 **“查看详情”** 按钮。 | 这个按钮是进入活动后台运营中心的唯一入口，普通用户不可见。 |
| **普通用户** | 无 | - |

## 3.2 仪表盘核心功能

点击“查看详情”后，管理者将进入一个包含以下功能的仪表盘页面。

### 3.2.1 参与者详情视图 (Participant Details)

此视图提供了一个完整的、可搜索的参与者数据库，帮助组织者全面了解参与情况。

| 数据板块 | 功能说明 |
|----------|----------|
| **提案列表** | - 展示所有与本活动关联的提案。<br>- 可按点赞、评论数排序。<br>- 点击可直接跳转到提案详情页。 |
| **团队列表** | - 展示所有报名参加的团队。<br>- 显示团队名称、成员人数、队长信息。<br>- 点击可查看团队主页和其关联的提案。 |
| **用户列表** | - 展示所有以个人或团队成员身份参与活动的用户。<br>- 可查看用户昵称和其所属团队。 |

### 3.2.2 活动数据分析 (Data Analytics)

此视图将活动的关键运营数据进行可视化展示，帮助组织者评估活动效果。

| 数据指标 | 图表类型 | 说明 |
|----------|----------|------|
| **报名趋势** | 时间序列折线图 | 展示活动自发布以来，每日新增报名用户/团队的数量。 |
| **参与度分析** | 关键数字 (KPIs) | 实时显示：<br>- **总报名数** (个人 + 团队成员)<br>- **总提交数** (已关联的提案数量)<br>- **总互动量** (活动相关内容的总点赞、评论数) |
| **内容热度榜** | 列表 | 展示本次活动中最热门的10个提案，按互动量排序。 |
